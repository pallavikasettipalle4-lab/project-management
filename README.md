# Project Management Module

A full-stack Project Management module developed as part of an Employee Task and Project Management System.

The application allows users to create, view, update, and manage projects, assign employees to projects, and track project status through a simple and responsive web interface.

## 🚀 Features

- Create new projects
- View all projects
- Update project details
- Delete projects
- Manage project status
- Assign employees to projects
- Add project description
- Set project start date
- Set project end date
- View total number of projects
- View active projects
- View completed projects
- Responsive user interface
- REST API integration
- MongoDB database integration

## 📌 Project Management

The Project Management module is responsible for creating and managing projects within the Employee Task and Project Management System.

Each project can contain:

- Project name
- Project description
- Project status
- Start date
- End date
- Assigned employees

### Project Status

- Active
- Pending
- Completed

## 🔗 API

The backend provides REST APIs for project management operations such as:

- Create project
- Get projects
- Update project
- Delete project

## 👩‍💻 Development

The project was developed using React.js for the frontend, Node.js and Express.js for the backend, and MongoDB with Mongoose for database management.
